# zippers

zippers is a suite of C++ programs that draw **zippers** on the spheres at infinity of hyperbolic manifolds. The
zippers Z⁺ and Z⁻ are defined in Danny Calegari and Ino Loukidou, *Zippers*
([arXiv:2411.15610](https://arxiv.org/abs/2411.15610)): two disjoint, path-connected subsets of the sphere at infinity
of a hyperbolic manifold that has a map to the circle. Each is drawn as a self-similar family of arcs, generated by a
substitution. The suite covers hyperbolic 3-orbifolds that fiber over the circle (zippers on S²), the
Cartwright–Steger complex hyperbolic surface (on S³), and a fibered hyperbolic 5-manifold of Italiano–Martelli–Migliorini
(on S⁴), together with the tools that make films of them.

**The state of the suite.** The three programs run on one shared library (`src/`): the batch programs are in `apps/`,
with the command lines of the original programs, which are in `legacy/` with their windows (the new programs have no
window yet). The tests in `tests/` re-run 46 reference runs (45 of them with the fast tests) and compare every output
with the recorded one. `docs/developer_guide.md` has the measurements and the traps of the code; each folder's
`README.md` says what is in it.

## Building

You need CMake 3.20 or later, a C++17 compiler and zlib, on macOS or Linux, and Python 3 (3.6 or later) for the
tests. The viewers also need GLUT and OpenGL: macOS has them; on Ubuntu or Debian install them with

    sudo apt-get install zlib1g-dev freeglut3-dev libglu1-mesa-dev

Then:

    make            # configure into build/ if needed, then build
    make test       # build, then run the fast tests
    make clean      # remove build/
    make sanitize   # build into build-sanitize/ with the address and undefined-behaviour sanitizers

The Makefile is a thin wrapper around CMake. To call CMake yourself, for example to leave out the viewers:

    cmake -S . -B build -DZIPPERS_VIEWERS=OFF
    cmake --build build
    ctest --test-dir build -L fast

The options (give them with `-D` to `cmake`, or through `make CMAKE_ARGS=...`):

| option | default | meaning |
|---|---|---|
| `ZIPPERS_VIEWERS` | ON | build the GLUT viewers |
| `ZIPPERS_SANITIZE` | OFF | build with the address and undefined-behaviour sanitizers |
| `ZIPPERS_FILM` | ON on macOS, OFF elsewhere | build the Swift film tools |
