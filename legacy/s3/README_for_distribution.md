# Zippers of the Cartwright–Steger surface

These programs draw approximations to the **zippers** Z⁺ (blue) and Z⁻ (red) on the 3-sphere at
infinity of the **Cartwright–Steger surface** X, a closed complex hyperbolic surface. They also find
**linked loops** in them: a loop in Z⁺ and a loop in Z⁻ with linking number ±1.

## Background

- **The group.** Γ = π₁(X) has index 864 in an arithmetic lattice of the simplest type in
  PU(2,1): Mostow's lattice, which is also a Deligne–Mostow lattice.
  - Cartwright and Steger give Γ by explicit 3×3 matrices over ℤ[ζ₁₂].
  - All group arithmetic here is exact in that ring, so group elements are recognised with no
    rounding.
- **The homomorphism.** X has b₁ = 2, and its Albanese map X → T is a genus-19 Lefschetz fibration
  over an elliptic curve with three nodes.
  - We use φ: Γ → ℤ, the first coordinate of H₁(Γ) = ℤ².
  - Composing the Albanese map with a projection T → S¹ gives a circle-valued Morse function with
    three critical points, all of index 2.
  - Its kernel K is finitely generated but not finitely presented (Llosa Isenrich–Py).
- **Zippers** (Calegari–Loukidou, *Zippers*, arXiv:2411.15610). Z⁺ ⊂ S³ is the set of endpoints of
  the quasigeodesics along which φ increases linearly; Z⁻ is the same for −φ. They are disjoint,
  dense and path-connected.

## Building

```bash
make
```

This needs a C++17 compiler and zlib.
- **macOS:** the viewer uses the system GLUT/OpenGL frameworks.
- **Linux:** install GLUT and zlib first (for example `freeglut3-dev` and `zlib1g-dev`); the
  makefile picks the right libraries. I have only tested the macOS build.
- `make nogui` builds `zipper3` without the viewer (PNG output only).

## Using the viewer

```bash
./zipper3 -v
```

This shows the 18 base arcs of each zipper in a stereographic projection of S³, centred at the
attracting fixed point t⁺ of the substitution element t.

```bash
./zipper3 -v --pairs linked_pairs.txt
```

This shows the 13 linked pairs of loops instead.

| key | action |
|---|---|
| mouse drag | rotate ℝ³ |
| arrows, `w`/`s` | move the pole of the projection; this rotates S³ itself |
| `z` / `x` | zoom in / out |
| `+` / `-` | add / remove the next shell of translates (denser zippers) |
| `]` / `[` | finer / coarser accuracy |
| `c` | show Z⁺ / Z⁻ / both |
| `b` | change the radius of the clipping ball |
| `n` / `N` | (pair mode) next / previous linked pair |
| `l` | (pair mode) show the base arcs faintly behind the pair |
| `r` | reset the view |
| `p` | save the window as a PNG |
| `q` | quit |

**PNG output without the viewer:**

```bash
./zipper3 -R 3 -a 0.005 -o picture.png
```

This draws more translates at a finer accuracy.

```bash
./zipper3 --pairs linked_pairs.txt --pairindex 5 --context -o pair.png
```

This draws one linked pair against the base arcs. Run `./zipper3 -h` for all options.

**Cost.** The number of translates grows quickly with `-R`.
- `-R 3` (19 translates) takes about a second.
- `-R 4` (331 translates) takes several seconds and about 1 GB of memory.

## The other programs

- **`chz`**: the exact group, and the block-filling search that produced `subst_4.00_9.50_t3.txt`.
  - `./chz selftest` checks the Cartwright–Steger data exactly.
  - `./chz kernel 4 9.5 3` reproduces the substitution data. It also proves that the 36 kernel
    elements of displacement ≤ 4 generate K.
- **`link3`**: linking numbers.
  - `./link3 selftest` checks the method on known links.
  - `./link3 -a 0.01 --nrel 20 --hr 2.6` is the search that found the linked pairs. It takes about
    15 minutes.
- **`cs_check.py`**: an independent numerical check of the matrices (needs numpy).
- **`encode_movie.swift`**: macOS only. It turns the frames written by
  `./zipper3 --pairs linked_pairs.txt --movie DIR` into an MP4 (`make encode_movie`).
- **`add_audio.swift`**: macOS only. It puts a soundtrack on the film, with fades (`make add_audio`).
  `--moviescript 1|3` chooses the 58-second film or the film to the fugue.

## How the arcs are made

The kernel K is generated by a finite set S. Fix t ∈ Γ with φ(t) = 3. For each s ∈ S, write
t⁻¹st = x₁⋯x_k as a word in S: this is the roof over the segment (1, s) in the staircase picture.
Then the arc α_s ⊂ Z⁺ from t⁺ to s·t⁺ is self-similar:

  α_s = t·(α_{x₁} ∪ x₁α_{x₂} ∪ ⋯ ∪ x₁⋯x_{k−1}α_{x_k}).

So it can be drawn by repeated substitution to any accuracy. The pictures show the translates g·α_s
for g in a hyperbolic ball about the basepoint. Z⁻ is the same with t⁻¹.
