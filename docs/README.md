# docs

- `user_guide.md`: for those who run the programs: the examples, every option of every command of `zippers`, pictures, polyline and session files, the data files, and what is checked and what is only measured.
- `developer_guide.md`: for those who change the code: its architecture, how to add an example or a geometry, the tests to add, and its measurements and traps, by part of the code.
- `gallery.md`: pictures of the three geometries, each with the command that makes it (`images/`).
- `background/zippers_note.pdf` (its source `zippers_note.tex`): an informal note, not for publication, by Danny Calegari and
  Claude (Anthropic), on the mathematics behind the programs: how the zippers and their base arcs are built, their
  connectivity, the examples, and linking at infinity.
